# 桌宠（桌面宠物）详细设计需求规范 (2D GIF版)

> 完整功能、状态机、GIF 编号映射、数据结构与验收方案见 `desktop_pet_full_design.md`。

---

## 一、 视觉与姿态设计（外观呈现）

### 1. 形象与技术实现
* **画面形式**：采用 **2D GIF 动态图（或 APNG / PNG 序列帧）** 渲染，轻量化且易于资源制作与替换。
* **背景透明**：GIF/PNG 序列必须自带 Alpha 透明通道，确保边缘平滑无锯齿、无矩形外框遮挡桌面背景。
* **尺寸缩放**：支持自由缩放（如 50%~200%），适配不同分辨率屏幕。
* **换装与皮肤**：通过加载/切换不同套系的 GIF 图像资源包，实现服装与形态切换。

### 2. 动画动作库（GIF资源集）
* **待机状态（Idle）**：呼吸、眨眼、晃头、小幅度原地动作（如看书、听音乐、晃脚）的循环 GIF。
* **移动姿态**：沿任务栏/窗口边缘行走、跑动、下落的位移动画。
* **受击/被动状态**：被点击、被拖拽、悬空晃动时的特定 GIF 反馈动画。
* **特殊状态**：睡觉（夜间自动触发）、进食、生病、打瞌睡等专属 GIF 序列。

## 二、 交互与反馈机制（动作互动）

### 1. 鼠标与触控操作
* **左键单击**：随机切换播放一段互动 GIF 动作，并伴随文本气泡或特定语音（如开心打招呼）。
* **左键双击**：打开主菜单或功能面板。
* **长按拖拽**：按下左键切换为“被拎起/悬空”GIF，拖拽至屏幕任意位置放开，触发**物理下落/坠落**动画 GIF。
* **右键点击**：弹出系统快捷菜单（设置、隐藏、功能选单等）。
* **滚轮滑动**：直接调整桌宠大小或音量大小。

### 2. 气泡对话与音效
* **文本气泡**：头顶弹出文字对话框，支持设置停留时间与打字机效果。
* **语音配音**：播放 GIF 动画时同步播放短音效或角色配音（可随时开启/静音）。

---

## 三、 桌面系统适配（系统与性能）

### 1. 悬浮与窗口层级
* **置顶显示**：可选择“始终置顶”或“跟随桌面（隐藏在其他应用下方）”。
* **鼠标穿透（点击透传）**：开启后，鼠标点击桌宠位置会直接操作其下方的窗口，不影响正常办公与游戏。
* **边缘吸附**：靠近屏幕边界时自动贴边隐藏或露出一半。

### 2. 物理碰撞与环境感知
* **窗口识别**：能够站在当前打开的软件窗口顶端（如浏览器顶部），或沿着窗口边缘爬行。
* **昼夜与时间感知**：根据系统时间自动切换对话内容（早上问好、夜间睡觉切换为睡觉 GIF）。
* **天气感知**：获取本地天气，下雨时展示撑伞 GIF，降温时穿上厚衣服。

### 3. 性能优化
* **开机自启**：系统启动时后台静默加载。
* **极低性能占用**：得益于 2D GIF/序列帧实现，CPU 占用率低于 1%，内存占用低于 80MB。在运行大型游戏时可自动冻结 GIF 刷新或隐藏。

## 四、 实用小工具（效率与日常辅助）

| 功能模块 | 具体设计要求 |
| :--- | :--- |
| **定时提醒** | 支持闹钟、倒计时、番茄钟模式（工作25分钟，桌宠提醒休息5分钟）。 |
| **健康关怀** | 久坐提醒（每小时提醒站立）、喝水提醒、眼部疲劳提醒。 |
| **系统监测** | 实时监测 CPU/内存占用率、电量、网速；硬件过热或内存过高时展示紧张/发烫 GIF。 |
| **快捷工具箱** | 点击可快速打开指定的本地程序（如计算器、记事本）或网页链接。 |
| **便签/备忘录** | 可随手记录待办事项（To-Do List），交由桌宠展示在气泡中。 |

## 五、 属性与成长系统（养成要素）

* **数值指标**：
  * **饱腹度**：随时间消耗，可通过“吃饭”补充；营养餐和冰淇淋同时恢复体力（长时间不吃饭触发饥饿 GIF 动作）。
  * **心情值**：通过游戏、摸摸互动和运动增加，长时间忽视会降低。
* **体力值**：清醒时默认仅降低 0.2 点/小时；运动、工作和游戏按所选时长消耗体力，吃饭与睡眠恢复体力。
* **好感度/等级**：
  * 随着互动时间增加，提升好感等级。
  * 好感度提高后，解锁更多专属动作 GIF、语音、隐藏皮肤与新对话。

---

## 六、 智能对话（接入大语言模型）

* **AI 聊天**：支持在对话框中输入文字进行自由交流。
* **主动关怀**：在特定场景下主动弹出气泡（如好久没有互动时主动吸引注意）。
* **记忆功能**：记录用户的称呼、偏好与习惯，并在日常对话中体现。

---

## 七、 系统控制面板（设置菜单）

* **常规设置**：开机自启、窗口置顶、鼠标穿透开关、语言切换。
* **声音与图像**：音量调节、音效开关、缩放比例调节、帧率/GIF 播放速度控制。
* **快捷键（热键）**：设置一键召唤/隐藏桌宠的键盘快捷键。
* **数据管理**：支持养成进度、配置信息的本地备份与恢复。

## 八、当前实现状态与完整版开发基础

项目按本文件的完整功能范围继续开发。当前已经稳定实现的基础能力如下：

* **标签驱动动画**：M1～M3 已接入 `action_manifest.json`，61 个核心 GIF 按角色、状态和用途选择，不再按文件名猜测动作；完整 202 个 GIF 目录已按待机、睡眠、食物、运动、移动、情绪等类别整理。
* **三层自然待机**：持续微动作、45~90 秒姿态变化、4~12 分钟场景动作分层调度；随机单次姿态完整播放 2 遍，随机场景单次持续 50~150 秒，均为上一版的 2 倍；特殊动作使用洗牌袋且有冷却时间。
* **基础互动**：单击从 10 个互动动作中无重复抽取，完整播放后回到基础待机；双击打开控制面板。
* **悬停界面**：鼠标停在宠物上方时自动显示紧凑状态卡；互动栏按吃饭、运动、工作、游戏、工具分类，默认在角色右侧，右侧空间不足时自动换到左侧。状态卡、多级菜单按当前显示器实际可见区域收拢，活动时显示名称和剩余分钟。
* **日常关怀**：启动问候根据早晨、中午、下午、晚上和深夜变化；久坐、喝水、护眼提醒可独立开关和设置间隔。
* **窗口控制**：支持拖动、50%~200% 缩放、强力置顶、鼠标穿透、隐藏、暂停、召回和退出。
* **全局快捷键**：支持 `Ctrl+Alt+D` 隐藏/显示、`Ctrl+Alt+T` 穿透开关、`Ctrl+Alt+P` 召回、`Ctrl+Alt+Space` 暂停/恢复。
* **设置记忆**：自动保存位置、大小、置顶、穿透、动画速度和健康提醒开关。
* **多屏保护**：显示器拔除或排列变化后，自动把桌宠限制在最近显示器的可见工作区内。
* **单实例运行**：重复启动 EXE 时只保留一只桌宠，并尝试唤回已有窗口。
* **性能基础**：刷新上限为 30 FPS，GIF 按需解码，动画缓存上限为 8 个，不一次载入全部素材。
* **桌面物理**：M2 已实现真实时间步长重力、轻/中/重落地、普通窗口顶部碰撞、支撑窗口跟随、任务栏上方落地和碰撞开关。
* **边缘行为**：距离屏幕左右边缘 32 像素内吸附；无操作 3 秒后播放 `103`“白狗墙后探头”。原图墙在右侧，因此右边缘使用原图、左边缘水平镜像；光标靠近、气泡出现或开始拖动时恢复基础待机。
* **随机巡游**：仅在角色位于当前显示器底部、用户无操作且不处于提醒/睡眠/拖拽时低频触发；动作池为 `001` 开车、`046` 与 `097` 贴地翻滚、`052` 双宠追逐、`053` 双宠交错奔跑、`080` 黄狗驮白狗奔跑、`086` 白狗趴地蠕动和 `182` 骑马。每项使用独立速度，并根据移动方向水平镜像。`111` 是“白狗张嘴小惊讶”，只用于点击反馈。
* **养成系统**：M2 已实现饱腹、心情、体力、清洁、健康、好感、经验和等级；自然状态默认每 10 分钟结算，离线补算上限 72 小时。饱腹、心情、清洁和低状态健康损耗按旧版 2 倍速度下降，体力默认缓慢降低 0.2 点/小时。
* **照顾与活动**：吃饭可选营养餐和冰淇淋并恢复体力；运动可选热身、啦啦操、跑步，工作可选写笔记、电脑办公、上班中，游戏可选摸摸互动、手柄游戏、一起说相声。工作提供 15/30/60 分钟，运动和游戏提供 5/15/30 分钟，数值按时长比例变化。
* **等级解锁**：使用 1～10 级固定累计经验表；低等级动作池受限，升级后逐步开放音乐动作和场景待机。
* **计时工具**：M3 已实现 1 分钟～24 小时倒计时、按星期重复闹钟和 25/5 番茄钟；工作、休息、完成分别连接对应 GIF。
* **便签待办**：M3 已实现新建、搜索、完成、推迟、删除、7 天回收站、恢复和 UTF-8 文本导出，数据保存至 SQLite。
* **系统与工具**：M3 已实现 CPU、内存、电池、网络监测，计算器、记事本、截图、资源管理器、自定义工具、提醒音和开机自启；控制面板和四个内置工具可直接从侧边栏“工具”打开。
* **菜单分工**：照顾操作放在角色侧边按钮列并自动避让屏幕边缘；右键菜单只负责窗口、行为、物理和启动配置。

昼夜、天气、换装、AI 对话、隐私、数据备份和完整异常验收仍按 M4～M5 范围继续开发；未完成前，当前 EXE 不声称是最终完整版。

## 九、GIF 动作标签库

原始动态素材目录实际包含 202 个 GIF，其中 200 个为编号动作，2 个为素材宣传图。所有文件已经逐帧检查并建立标签，原始 GIF 不改名、不覆盖。

* `..\assets\catalog\gif_action_catalog.html`：可搜索、筛选并直接播放 GIF 的本地设计目录。
* `..\assets\catalog\gif_action_catalog.csv`：可用 Excel 打开，适合排序、筛选和动作选型。
* `..\assets\catalog\gif_action_catalog.json`：供桌宠程序按状态、角色和用途自动读取动作。
* 标签字段包括动作名称、分类、角色外观、推荐用途、优先级、关键词、动作说明、帧数、循环时长、画布尺寸、透明背景和文件校验值。
* 两张宣传 GIF 的优先级标记为“排除”，不得作为桌宠动作载入。
