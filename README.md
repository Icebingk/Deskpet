# 线条小狗 2D 桌宠

这是一个使用透明 GIF 素材制作的 Windows 桌宠，不需要 3D 模型或建模软件。

## 直接运行

当前发布文件为 `dist\线条小狗桌宠.exe`，可直接双击运行；电脑无需安装 Python。

## 项目结构

- `deskpet\`：桌宠主程序源码。
- `pet_assets\`：程序实际使用的精选 GIF。
- `素材\`：完整原始素材，只作归档和选图。
- `catalog\`：GIF 标签、检索目录和标签修正数据。
- `docs\`：需求规范与完整版设计文档。
- `tests\`：自动化测试。
- `tools\`：PyInstaller 打包辅助文件。
- `dist\`：可直接运行的正式版 EXE。
- `action_manifest.json`：运行时动作映射，保留在根目录。

## 功能

- 61 个核心 GIF 由动作标签和 Manifest 驱动；完整 202 个 GIF 已按待机、睡眠、食物、运动、移动、情绪等类别整理。
- 持续微动作、低频姿态和场景动作分层调度；随机单次姿态会完整播放 2 遍，随机场景会持续 50～150 秒，持续时间均为上一版的 2 倍，明显特殊动作不会连续触发。
- `111` 是“白狗张嘴小惊讶”，仅用于点击反馈。角色站在屏幕底部时，会从开车、两种贴地翻滚、双宠追逐、双宠交错奔跑、黄狗驮白狗奔跑、白狗趴地蠕动和骑马中低频选择一种移动到另一侧，并按实际方向镜像。
- 单击从 10 个互动动作中无重复抽取，并显示中文打字机气泡。
- 左键拖动桌宠；松手后按真实时间步长下落，可站在普通窗口顶部或任务栏上方。
- 被站立窗口移动、最小化或关闭后，桌宠会跟随或重新下落；关闭窗口碰撞时保持松手位置。
- 靠近屏幕左右边缘会吸附，3 秒无操作后播放 `103`“白狗墙后探头”；右边缘使用原图，左边缘自动水平镜像。
- 睡眠使用 `199` 打哈欠后转入 `160` 双宠抱着入睡；`035` 和 `097` 不再误作睡眠。
- 鼠标悬停在角色上方时，自动显示紧凑状态卡；互动栏按吃饭、运动、工作、游戏、工具分类，默认位于角色右侧，右侧空间不足时自动换到左侧，状态卡和多级菜单始终限制在当前屏幕可见范围内。
- 状态卡离开鼠标后自动收起，气泡出现时暂时隐藏状态卡，避免遮挡角色和文字。
- 鼠标滚轮可在 50%～200% 范围调整大小；M3 默认角色尺寸比上一版缩小 30%。
- 自然状态默认每 10 分钟统一结算：饱腹、心情、清洁和低状态健康损耗为旧版 2 倍速度，清醒体力仅缓慢下降 0.2 点/小时；三种运动的体力消耗默认为原来的 2 倍，睡眠恢复体力。结算周期和三项速率均可在“控制面板 → 外观与行为 → 养成参数”修改，离线补算最多 72 小时。
- 营养餐和冰淇淋都会恢复体力；工作可选 15/30/60 分钟，运动和游戏可选 5/15/30 分钟，数值效果按时长成比例结算。摸摸已归入游戏，活动期间循环播放对应 GIF，悬停状态卡显示剩余分钟。
- 右键菜单只保留控制面板、缩放、置顶、穿透、暂停、健康提醒、重力、窗口碰撞、边缘吸附、开机自启、召回、隐藏和退出等配置项。
- 强力置顶会定期恢复被普通窗口改变的层级，并且不会抢夺键盘焦点。
- 透明无边框窗口，默认显示在桌面右下角。
- 双击角色打开普通标题栏控制面板。
- 菜单可开启或关闭健康提醒，并可一键让桌宠回到桌面右下角。
- 启动问候会随早晨、中午、下午、晚上和深夜变化。
- 自动记住位置、大小、窗口与物理设置；成长数据单独原子保存。
- 更换或断开显示器后，会自动把桌宠移回可见区域。
- 重复双击 EXE 只保留一个桌宠实例。
- 控制面板包含首页、计时、便签、外观与行为、系统与工具五页。
- 支持倒计时、按星期重复闹钟、25/5 番茄钟、久坐/喝水/护眼提醒。
- 支持便签搜索、完成、推迟、7 天回收站、恢复与 UTF-8 文本导出。
- 支持 CPU、内存、电池、网络监测，系统未提供温度时明确显示“系统未提供”。
- 侧边栏“工具”可直接打开控制面板、计算器、记事本、截图和资源管理器；控制面板仍支持经过路径校验的自定义工具。
- 支持提醒音、互动音开关和当前用户开机自启。

## 全局快捷键

- `Ctrl + Alt + D`：隐藏或显示桌宠。
- `Ctrl + Alt + T`：开启或关闭鼠标穿透。
- `Ctrl + Alt + P`：召回桌宠到桌面右下角。
- `Ctrl + Alt + Space`：暂停或恢复主动动作。

## 从源码运行

先安装 Python 3.11 或 3.12，然后在项目目录执行：

```powershell
python -m pip install -r requirements.txt
python deskpet2d.py
```

也可以在依赖安装完成后双击 `start_2d.bat`。

## GIF 动作素材目录

- 双击 `catalog\gif_action_catalog.html`：搜索、筛选并直接播放全部 GIF。
- `catalog\gif_action_catalog.csv`：使用 Excel 查看全部动作标签和技术信息。
- `catalog\gif_action_catalog.json`：供程序设计和自动动作选择使用。

全部 202 个 GIF 均已标注；原素材没有被重命名或修改。
